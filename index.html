API setup

Demo mode uses sample data. For real scores, configure a cricket API token on the server; never paste private API keys into browser code.

1. Create an account with your chosen cricket data provider and check its live-match and scorecard coverage.
2. Copy its API token from the provider dashboard.
3. In the project folder, copy .env.example to .env.
4. Set DEMO_MODE=false, add your token as CRICKET_API_TOKEN=your_token, and set CRICKET_API_BASE to the provider's documented base URL.
5. Restart the server with npm start. If the provider uses different endpoint paths or JSON fields, update server.js to match its official docs.

Example adapter default: CricketLiveApi-style endpoints /matches/live and /scorecard/{matchId}. Provider access, pricing, coverage, and exact response fields depend on your plan and must be verified with the provider.
